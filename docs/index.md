# sdf-xarray

`sdf-xarray` provides a backend for [xarray](https://xarray.dev) to
read SDF files as created by the [EPOCH](https://epochpic.github.io)
plasma PIC code.

`sdf-xarray` uses the [SDF-C](https://github.com/epochpic/SDF_C) library.
